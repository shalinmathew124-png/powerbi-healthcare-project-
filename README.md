# Power BI Healthcare Appointment Dashboard

## Project Overview
This project is a healthcare analytics dashboard created in Power BI. It analyses patient appointment data to identify patterns in appointments, cancellations, waiting times and department performance.

## Tools Used
- Power BI
- Excel
- DAX
- Data Visualisation
- Healthcare Data Analysis

 ## Key Features
- Total appointments analysis
- Cancellation and no-show tracking
- Department-wise appointment trends
- Waiting time analysis
- Interactive filters and slicers

## Key Insights
- Identified appointment trends across departments
- Highlighted cancellation/no-show patterns
- Compared waiting times by department
- Created clear visuals for healthcare administration decision-making

## Skills Demonstrated
- Power BI dashboard creation
- Data cleaning
- KPI reporting
- DAX measures
- Healthcare analytics
- Data storytelling

## How to View
Download the `.pbix` file from this repository and open it using Microsoft Power BI Desktop.

## Project Purpose
This project was created as part of my portfolio to demonstrate my Power BI and healthcare data analytics skills for healthcare administration, eHealth, and data analyst roles.
